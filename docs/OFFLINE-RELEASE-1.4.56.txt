Hotel System v1.4.56 — Offline release
======================================
Date: 2026-10-16
No internet required on the hotel PCs.

BUILD (on your build machine)
-----------------------------
  pnpm release
  or:  .\packaging\windows\Build-Release.ps1 -SkipAndroid
  → releases\v1.4.56\HotelSystem-Setup-1.4.56.exe

INSTALL / UPGRADE (Main PC)
--------------------------
  1. Copy HotelSystem-Setup-1.4.56.exe to USB or LAN share.
  2. On Main server PC: run as Administrator.
  3. Do NOT uninstall first — install over the existing copy.
  4. Live data is kept.

AFTER UPGRADE
-------------
  Menu sales report
  • Close → Menu sales PDF — full menu product report for the business day.
  • Includes paid bills + credit sales (open table unpaid not included).
  • Download anytime = sold up to that moment for the selected date.

  Printers
  • Main server must NOT appear under Cashier PCs (auto-removed / Remove PC).
  • Server printers: Settings → + Add → LAN (IP) or USB/Windows (this server PC).
  • Online = LAN port 9100 or Windows spooler (not “open desktop app” on Main PC).

  Takeaway
  • Cashier: Start cooking → Mark ready → Served, then pay/close.

  Bill edit
  • Remove item → total drops; kitchen gets CANCELLED slip for removed lines
    + reprint of remaining items. Stock restores (no full cancel needed).

ADDITIONAL / CASHIER PCs (other counters only)
----------------------------------------------
  Open Hotel desktop app (not browser only).
  Not the Main server PC.
