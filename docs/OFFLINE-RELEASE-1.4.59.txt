Hotel System v1.4.59 — Offline release
======================================
Date: 2026-10-16
No internet required on the hotel PCs.

BUILD (on your build machine)
-----------------------------
  pnpm release
  or:  .\packaging\windows\Build-Release.ps1 -SkipAndroid
  → releases\v1.4.59\HotelSystem-Setup-1.4.59.exe

INSTALL / UPGRADE (Main PC)
--------------------------
  1. Copy HotelSystem-Setup-1.4.59.exe to USB or LAN share.
  2. On Main server PC: run as Administrator.
  3. Do NOT uninstall first — install over the existing copy.
  4. Live data is kept.

AFTER UPGRADE
-------------
  Business day (opening → next opening) — no previous-day mix
  • Dashboard, Sale Audit, Close report, Billing, Payments / Cash,
    Finance, Hotel Expenses, Menu sales PDF, Store purchases, Workers.
  • “Today” = only orders / payments after Settings → Business day starts
    (e.g. 10:00 opening). Last night’s sales stay on yesterday.
  • After Close for a date, that day is locked (hotel closed for that day).
  • Set Day start in Settings to your real opening time (e.g. 10:00).

  Menu sales PDF (Close)
  • Paid + credit items for that business day only.
  • Per Head section unchanged.
  • Does not pull previous business day’s dishes into today’s report.

  Also from 1.4.58
  • Reverse payment → Unpaid (edit / pay again; no cancel slip).

ADDITIONAL / CASHIER PCs (other counters only)
----------------------------------------------
  Open Hotel desktop app (not browser only).
  Not the Main server PC.
