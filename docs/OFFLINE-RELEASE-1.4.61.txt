Hotel System v1.4.61 — Offline release
======================================
Date: 2026-10-17
No internet required on the hotel PCs.

BUILD (on your build machine)
-----------------------------
  pnpm release
  or:  .\packaging\windows\Build-Release.ps1 -SkipAndroid
  → releases\v1.4.61\HotelSystem-Setup-1.4.61.exe

INSTALL / UPGRADE (Main PC)
--------------------------
  1. Copy HotelSystem-Setup-1.4.61.exe to USB or LAN share.
  2. On Main server PC: run as Administrator.
  3. Do NOT uninstall first — install over the existing copy.
  4. Live data is kept.

AFTER UPGRADE
-------------
  Settings → Network health & machine logs
  • Check network health: DB, LAN IPs, mDNS, Cashier PCs online/offline, LAN printers.
  • Machine logs per PC (Main + Cashier): login, hotel open/close, orders, payments,
    settings, printer Active on/off, print OK/FAIL, Cashier register/reconnect.
  • Refresh logs after actions; text is readable on light background.

  Also from 1.4.60
  • Business shift open → close (Settings: Shift opens + Shift closes, e.g. 10:00 → 03:00).
  • Hotel Open/Close does not change the business date.

ADDITIONAL / CASHIER PCs (other counters only)
----------------------------------------------
  Open Hotel desktop app (not browser only).
  Not the Main server PC.
