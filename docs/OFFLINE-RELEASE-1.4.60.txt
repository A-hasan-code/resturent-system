Hotel System v1.4.60 — Offline release
======================================
Date: 2026-10-16
No internet required on the hotel PCs.

BUILD (on your build machine)
-----------------------------
  pnpm release
  or:  .\packaging\windows\Build-Release.ps1 -SkipAndroid
    10|  → releases\v1.4.60\HotelSystem-Setup-1.4.60.exe

INSTALL / UPGRADE (Main PC)
--------------------------
  1. Copy HotelSystem-Setup-1.4.60.exe to USB or LAN share.
  2. On Main server PC: run as Administrator.
  3. Do NOT uninstall first — install over the existing copy.
  4. Live data is kept.

AFTER UPGRADE
-------------
  Business shift (open → close) — stops previous-day mix
  • Settings → Shift opens (e.g. 10:00) + Shift closes (e.g. 03:00 next morning).
  • Dashboard, Audit, Close, Billing, Payments, Finance, Expenses, Menu sales
    use only that open → close window (not open → next open 24h).
  • Hotel Open / Close does NOT change the business date — only these clocks do.
  • After shift close time until next open, sales belong to the upcoming day
    (they stay out of yesterday’s locked report).
  • Set Open 10:00 and Close 03:00 if that is your real hotel shift.

  Also from 1.4.59
  • Menu sales PDF for the selected business day.
  • Reverse payment → Unpaid (edit / pay again).

ADDITIONAL / CASHIER PCs (other counters only)
----------------------------------------------
  Open Hotel desktop app (not browser only).
  Not the Main server PC.
