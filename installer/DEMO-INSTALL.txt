Hotel System — Demo Installer
================================

FOR THE CLIENT (demo PC)
------------------------
1. Copy the WHOLE project folder to the PC (USB / zip).
2. Open folder:  installer\
3. Double-click:  HotelSystem-Setup.exe
   (or "Setup Hotel System.bat" if .exe not built yet)
4. Allow Administrator when Windows asks.
5. Wait — installer will:
   - Check / install Docker Desktop
   - Enable needed Windows features when possible
   - Create Docker network + start database + API + website
   - Create Desktop shortcuts (Start / Stop)
   - Open http://localhost:3000

6. If Docker was installed for the FIRST time:
   - Restart Windows once
   - Then double-click Desktop: "Start Hotel System"

---------------

FOR YOU (developer — build the .exe once)
-----------------------------------------
1. Open PowerShell in this installer folder
2. Run:
     powershell -ExecutionPolicy Bypass -File .\Build-SetupExe.ps1
3. File created: HotelSystem-Setup.exe
4. Zip the full project (or give USB with full folder) to the demo client.


NOTES
-----
- First run needs INTERNET (Docker + image download).
- After images are cached, can run offline on that PC.
