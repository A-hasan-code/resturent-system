Hotel System — Client Pack (NO source code)
===========================================

WHAT IS THIS?
-------------
Pre-built Docker images + installer.
Client does NOT get your apps/ source code.


FOR THE CLIENT
--------------
1. Extract this whole folder (keep all files together).
2. Double-click:  HotelSystem-Setup.exe
3. Allow Administrator.
4. Wait (loads images + starts app).
5. Browser opens: http://localhost:3000

If Docker was installed for the first time:
  → Restart PC once
  → Then Desktop: "Start Hotel System"
